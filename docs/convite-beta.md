# Convite Beta Testers — SantuarioEdu

Mensagens prontas pra convidar os primeiros 5-10 testadores. Copie a versão adequada ao canal.

Como funciona o feedback:
- Beta clica no botão **"Feedback"** flutuante (canto inferior direito) em qualquer página logada
- Preenche categoria (bug/sugestão/dúvida) + mensagem
- Cria ticket no admin + notifica seu Gmail `suporte.santuarioedu@gmail.com`
- Você responde direto pelo email OU pelo painel admin `/admin/quiz/ticketsuporte/`

## 📋 Perfis de beta tester recomendados (mix ideal)

Tenta variar os perfis pra pegar feedback amplo:

| Perfil | Por quê |
|---|---|
| 1-2 **concurseiros ativos** (estudando pra prova real) | Feedback mais valioso — testa fluxo real |
| 1-2 **estudantes universitários** | Testam UX genérica, sem viés de concurso |
| 1-2 **profissionais de TI/dev** | Vão achar bugs técnicos, edge cases, problemas de acessibilidade |
| 1-2 **pessoas leigas em tech** | Melhor pra testar clareza da UX, onboarding |
| 1 **amigo(a) próximo(a)** | Vai te falar as verdades duras que outros não falam |

## 🎯 Como saber se o beta foi bem-sucedido

Objetivos claros pra medir sucesso do beta:

- **>= 60% dos betas completam onboarding** (indica que fluxo pós-signup está claro)
- **>= 50% respondem >= 10 questões** (indica engajamento inicial OK)
- **>= 40% voltam no dia seguinte** (retention D+1 — teste real do welcome email + lembrete)
- **>= 3 bugs reportados** (se ninguém reportar nada, ou não testaram ou o FAB tá invisível)
- **>= 1 sugestão de feature** (indica que estão engajados o suficiente pra pensar sobre)

Se atingir esses, tá pronto pro lançamento amplo. Se não, ajusta o que os betas mostraram e faz uma segunda rodada.
